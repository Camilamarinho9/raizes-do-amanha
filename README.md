# 🌱 Raízes do Amanhã

**Concurso Agrinho 2026 — Categoria: Programação Front-End**  
**Tema:** Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente

---

## 📌 Objetivo

O site *Raízes do Amanhã* foi desenvolvido para apresentar de forma interativa e acessível a importância do agronegócio sustentável brasileiro. O projeto aborda temas como sustentabilidade no campo, tecnologia agrícola, preservação da natureza e curiosidades do setor, sempre conectando produção e meio ambiente.

---

## 🚀 Funcionalidades

- Navegação suave entre seções com indicador de seção ativa na navbar
- Sistema de **3 idiomas** (Português, Inglês e Espanhol) com troca dinâmica de todos os textos da página
- **Modo escuro e claro** com preferência salva na sessão
- **Controle de tamanho de fonte** (A+ / A−) para acessibilidade
- Animações de **fade-in** ao rolar a página (Intersection Observer)
- Seção de **curiosidades** rotativas sobre o agronegócio
- **Quiz interativo** com pontuação, ranking e mensagens temáticas
- Animações **canvas estilo matrix** nas seções de Curiosidade e Quiz
- **Formulário de contato** com validação de campos e e-mail via JavaScript
- Folhas decorativas com animação ao clique
- Navbar que esconde ao rolar para baixo e reaparece ao rolar para cima ou aproximar o mouse do topo

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura semântica com tags `section`, `nav`, `footer`, `label`, `input`, `button`, `textarea`
- **CSS3** — variáveis CSS, Flexbox, Media Queries (responsivo para celular e tablet), animações com `@keyframes` e transições
- **JavaScript** — manipulação do DOM, funções, variáveis, eventos, `sessionStorage`, `IntersectionObserver`, `Canvas API`, validação com Regex
